Research Interests

My research aims to build robotic systems that are reactive at the level of control and general at the level of task reasoning. I currently work on humanoid loco-manipulation and dexterous manipulation, where the research problem I find most compelling is how a learned controller and a high-level policy should be coupled. I think about it along two axes.

The interface between levels. How to build a hierarchy across modules that run at different control frequencies and levels of abstraction, from RL-trained controllers to VLAs or agentic systems, and what interface should sit between them.

Generalization through hierarchy. How such a system generalizes, and especially whether the hierarchy itself can be an advantage for generalization rather than a compromise forced by control rate.

Recently I have been drawn to the idea that the high level should give only a coarse representation of the task, while the controller owns more of the instinct-level intelligence and carries its own information about the object it acts on.

Research

Ctrl-F: Force as an Interface for Humanoid Loco-Manipulation

Mengjie Zhao*, Yuxin Chen*, Yiyang Shao, Chuye Hong, Jiakang Chen, Koushil Sreenath, Masayoshi Tomizuka * Equal contribution
Under review at ICRA 2027. IROS 2026 S2RCC Workshop.

Paper Project page

Ctrl-F proposes contact force as the interface between high-level planning and whole-body control, so that one controller can handle many objects and interaction types, and a learned planner can adapt the force online.

SONAR: Can We Tune Humanoid Behavior Foundation Models for Dynamic and Contact-Rich Tasks?

Mengjie Zhao*, Yuxin Chen*, Shaoting Zhu, Yu Hong, Yunshen Wang, Yicheng Liu, Baijun Ye, Xiaoyu Tian, Baoxiong Jia, Hang Zhao, Siyuan Huang, Masayoshi Tomizuka * Equal contribution
RSS 2026 ExWBC Workshop (Oral); RSS 2026 WCBM Workshop. Journal version in preparation.

SONAR asks whether perception, with an object mask as task semantics, can let a frozen humanoid behavior foundation model correct its motion locally when the reference motion is imperfect.

BURGER: Benchmarking and Understanding Robotic Generalization via Embodied dRawing

Xiangyu Xu*, Bangshuai Peng*, Ziyi Liu*, Mengjie Zhao*, Chenhao Lu, Zhengyang Fan, Huazhe Xu, Kaizhe Hu * Equal contribution
Under review at ICRA 2027

Paper Code Project page

BURGER proposes embodied drawing as a benchmark for robotic generalization: drawing tasks carry rich semantic and spatial structure, scale in difficulty, and are scored automatically, which makes generalization measurable.

Hiking in the Wild: A Scalable Perceptive Parkour Framework for Humanoids

Shaoting Zhu*, Ziwen Zhuang*, Mengjie Zhao, Kun-Ying Lee, Hang Zhao * Equal contribution
CoRL 2026

Paper Code Project page Video

Hiking in the Wild proposes a scalable framework for perceptive humanoid locomotion, training a single policy that transfers from simulation to unstructured outdoor terrain.

Deep Whole-body Parkour

Ziwen Zhuang, Shaoting Zhu, Mengjie Zhao, Hang Zhao
arXiv, 2026. Released with Hiking in the Wild as Project Instinct (800+ GitHub stars)

Paper Code Project page Video

Deep Whole-body Parkour adds depth perception to whole-body control, so that a humanoid tracking a reference motion can adapt to the terrain it actually encounters.

PrO: Latent Proprioceptive Odometry for Goal-Reaching via Real-World Reinforcement Learning

Zhaoyang Cheng*, Hongde Hao*, Mengjie Zhao, Shaoting Zhu, Hang Zhao * Equal contribution
Under review at ICRA 2027

PrO proposes learning a latent odometry representation from proprioception alone, and shows it can be trained for goal-reaching directly in the real world with reinforcement learning.
